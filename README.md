# Project 07. 가상 센서 시뮬레이터 기반 스마트 자세 교정 방석

> 방석 네 모서리의 압력으로 앉은 사람의 무게중심을 계산하고, 나쁜 자세가 계속되면 진동으로 알려주는 시스템.
> 실제 센서 없이도 알고리즘을 검증할 수 있도록 **가상 센서 시뮬레이터**를 함께 만들었다.

## 1. 기본 아이디어 및 1차 구현 설계
- **아이디어 개요:** 방석 네 모서리에 압력 센서를 두고 착석자의 무게중심을 실시간으로 추적하여, 불량 자세가 일정 시간 이상 지속되면 진동 모터로 바른 자세를 유도하는 헬스케어 기기.
- **하드웨어 구성(원안):** FSR-402 압력 센서 4개, 코인형 진동 모터, 트랜지스터 드라이버, Arduino Nano
- **본 구현의 기술 스택:** Python, Streamlit(화면), NumPy(계산), Plotly(그래프)
- **1차 알고리즘:** 4점 압력의 모멘트 평형으로 무게중심 계산 → 원점에서 일정 거리 이상 벗어나면 경보

### 핵심 물리: 모멘트 평형으로 무게중심 구하기
시소에서 무거운 쪽으로 기울듯, 네 센서에 걸린 힘의 분포로 무게중심을 알 수 있다.

```
X_cg = Σ(F_i × x_i) / Σ F_i
Y_cg = Σ(F_i × y_i) / Σ F_i
```
- `F_i`: i번째 센서가 받는 힘, `x_i, y_i`: 그 센서의 위치
- 분자는 "힘 × 거리" = **토크(돌림힘)의 합**, 분모는 전체 체중
- 즉 "전체 토크를 전체 무게로 나누면 무게가 모인 한 점의 위치가 나온다"

## 2. 초기 바이브코딩 시 직면하는 문제점 (상용 제품 대비 한계)
- **하드웨어 없이는 검증 불가:** 센서와 아두이노가 없으면 코드가 맞는지 확인할 방법이 없고, 다양한 자세를 반복 실험하기도 어려움.
- **체형 차이에 따른 오경보:** 사람마다 골반 너비와 앉는 습관이 달라 원래 한쪽으로 치우쳐 앉는 사람은 항상 경보가 울림.
- **고쳐 앉기 오경보:** 잠깐 자세를 바꾸는 움직임까지 불량 자세로 판단함.
- **센서 드리프트:** FSR 필름이 오래 눌리면 값이 조금씩 변해 가짜 쏠림이 생김.
- **경보가 단순함:** "자세가 나쁘다"만 알려줄 뿐, 어떻게 고쳐야 하는지 알려주지 않음.

## 3. 단계적 문제 해결 및 고도화 전략

### [Step 1] 공학적 신호 처리 및 필터링 개선
- **가상 센서 시뮬레이터(확장):** 자세 시나리오(바른 자세 20초 → 다리 꼬기 25초 …)를 입력하면 4채널 압력 값을 자동 생성. 체중, 체형 편향, 노이즈, 드리프트를 조절해 다양한 조건을 반복 실험.
  - 무게중심이 (x, y)가 되도록 힘을 나누는 식: `F_i = W/4 × (1 + x·x_i)(1 + y·y_i)`
- **오토 테어(Auto-Tare):** 착석 후 처음 5초의 평균 위치를 그 사람의 기준 원점으로 등록 → 체형 차이 제거.
- **EMA 필터:** `새 값 = 0.2 × 측정값 + 0.8 × 이전 값` 으로 노이즈를 부드럽게.

### [Step 2] 해석역학(위상 평면) 기반 고도화
- **위상 평면 (X, dX/dt):** 위치만 보지 않고 **속도(위치가 변하는 빠르기)**를 함께 본다.
  - 위치는 벗어났지만 속도가 큼 → 고쳐 앉는 중 → 타이머 일시정지
  - 위치가 벗어났고 속도가 0 근처 → 그 자세로 굳음 → 타이머 증가
- **상태 머신:** 멈춘 채 안전 구역 밖에 15초 이상 머물면 진동 모터를 PWM 50 → 200으로 3초간 서서히 올림 (갑자기 세게 울려 반대로 과하게 쏠리는 현상 방지).

### [Step 3] 불량 자세 유형 분류와 맞춤 조언 (확장)
- 쏠린 방향의 각도로 유형을 분류: 좌/우 쏠림, 앞으로 숙임, 뒤로 기댐, 대각선 쏠림(다리 꼬기 의심)
- 유형별로 "다리를 풀고 양발을 바닥에 붙여보세요" 같은 구체적인 교정 조언 제공

### 결과 검증
기본 시나리오(8구간, 120초)에서 비교한 결과:

| 방식 | 경보 횟수 |
|---|---|
| 1차 단순 알고리즘 (보정·속도 판별 없음) | 13회 (대부분 오경보) |
| 개선 알고리즘 | 2회 (다리 꼬기, 앞으로 숙이기만 정확히 감지) |

## 4. 최종 바이브코딩 프롬프트 시퀀스

**[Step 1] 가상 센서 시뮬레이터**
```
Python으로 자세 교정 방석의 가상 압력 센서 시뮬레이터를 만들어줘:
1. 방석 네 모서리(좌앞, 우앞, 좌뒤, 우뒤)에 센서가 있다고 가정해줘.
2. "바른 자세 20초 → 다리 꼬기 25초"처럼 자세와 시간을 입력하면 20Hz로 4채널 압력 값을 만들어줘.
3. 체중, 체형 편향, 센서 노이즈, 드리프트를 조절할 수 있게 해줘.
```

**[Step 2] 무게중심 계산과 보정**
```
시뮬레이터 데이터로 무게중심을 계산하는 함수를 추가해줘:
1. 모멘트 평형식 X = Σ(F·x)/ΣF 로 무게중심을 구해줘.
2. 전체 힘이 작으면 '자리 비움'으로 처리해줘.
3. 착석 후 5초 평균을 기준 원점으로 삼고, EMA 필터로 노이즈를 줄여줘.
```

**[Step 3] 위상 평면 판별과 진동 알림**
```
불량 자세를 판별하는 상태 머신을 만들어줘:
1. 무게중심의 속도 dX/dt를 계산해줘.
2. 속도가 작고 안전 반경 밖에 15초 이상 있으면 불량 자세로 판단해줘. 움직이는 중에는 타이머를 멈춰줘.
3. 경보 시 진동 모터 PWM을 50에서 200까지 3초간 서서히 올려줘.
4. 쏠린 방향으로 불량 자세 유형을 분류하고 맞춤 조언을 보여줘.
```

**[Step 4] Streamlit 대시보드**
```
Streamlit으로 결과 화면을 만들어줘:
1. 시나리오를 표로 편집하고 '시뮬레이션 실행' 버튼을 눌러 결과를 보여줘.
2. 방석 위 무게중심 궤적, (X, dX/dt) 위상 평면, 시간별 타이머·PWM 그래프를 그려줘.
3. 자세 점수(%)와 단순 알고리즘 대비 경보 횟수를 비교해서 보여줘.
```

## 실행 방법
```bash
pip install -r requirements.txt
streamlit run app.py
```
